Quick guide

How to use the builder

  1. Choose a starting point.Pick a template or begin with a blank canvas.
  2. Build by dragging.Drag blocks into the canvas, or tap a block to add it on a phone.
  3. Edit and style.Select any item, then use the Style panel. Double-click text for inline editing.
  4. Add pages.Open Pages, add a page, then build it independently with the same blocks.
  5. Check and preview.Use device previews and the accessibility check before publishing.
  6. Save and export.Save locally, download a project backup, then export the generated HTML files.
Shortcuts: Ctrl/Cmd+S save · Ctrl/Cmd+Z undo · Ctrl/Cmd+D duplicate · Delete remove.
